# tr4tech — Site institucional

Site institucional da tr4tech, construído com TanStack Start, React e Tailwind CSS.

## Desenvolvimento

Requisitos: Node.js 20+.

```sh
npm install
npm run dev
```

## Build de produção

```sh
npm run build
npm run preview
```

## Stack

- TanStack Start
- TypeScript
- React
- Tailwind CSS
